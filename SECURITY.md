# Security policy

LensRelay is not ready for security-sensitive production use. No version is
currently supported because the project is still in its pre-alpha stage.

## Reporting a vulnerability

Please do not publish vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting feature for this repository when available. If it is
not available, contact the maintainer through the contact information on their
GitHub profile and include `LensRelay security` in the subject.

Reports should include the affected component, reproduction steps, expected
impact, and any known mitigation. Please avoid attaching real camera footage,
credentials, private keys, or other personal information.
